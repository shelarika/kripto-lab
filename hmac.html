MESSAGE AUTHENTICATION

HMAC

Hash-based Message Authentication Code untuk memastikan integritas dan autentikasi pesan menggunakan kunci rahasia.

01 — PENGENALAN

Apa itu HMAC?

⟡

HMAC atau Hash-based Message Authentication Code merupakan mekanisme autentikasi pesan yang menggunakan fungsi hash dan sebuah kunci rahasia.

HMAC dapat digunakan untuk membantu memastikan bahwa pesan tidak berubah selama proses pengiriman dan pesan berasal dari pihak yang memiliki kunci rahasia.

Pada Kripto Lab, kamu dapat memasukkan pesan dan kunci untuk menghasilkan nilai HMAC secara langsung.

02 — PROSES

Cara Kerja HMAC

01

Pesan

Pesan yang ingin dilindungi dimasukkan sebagai input algoritma.

02

Kunci Rahasia

Sebuah kunci rahasia digunakan sebagai bagian dari proses pembentukan HMAC.

03

Fungsi Hash

Pesan dan kunci diproses menggunakan fungsi hash untuk menghasilkan nilai autentikasi.

04

HMAC

Hasil akhirnya berupa message authentication code yang dapat digunakan untuk memverifikasi pesan.

03 — FORMULA

Rumus HMAC

HMAC: H((K' ⊕ opad) || H((K' ⊕ ipad) || M))

Keterangan: K = kunci, M = pesan, H = fungsi hash, ipad = inner padding, opad = outer padding.
