PUBLIC KEY ENCRYPTION

RSA-OAEP

Algoritma enkripsi asimetris yang menggunakan pasangan public key dan private key untuk melindungi pesan.

01 — PENGENALAN

Apa itu RSA-OAEP?

🗫

RSA-OAEP merupakan penerapan RSA dengan Optimal Asymmetric Encryption Padding. OAEP digunakan untuk memberikan padding pada pesan sebelum proses enkripsi RSA.

RSA menggunakan dua jenis kunci, yaitu public key dan private key.

Pada simulasi ini, public key digunakan untuk mengenkripsi pesan, sedangkan private key digunakan untuk melakukan dekripsi.

02 — PROSES

Cara Kerja RSA-OAEP

01

Generate Key

Sistem membuat pasangan public key dan private key.

02

OAEP Padding

Pesan diproses menggunakan mekanisme padding OAEP sebelum dienkripsi.

03

Enkripsi

Public key digunakan untuk mengenkripsi pesan menjadi ciphertext.

04

Dekripsi

Private key digunakan untuk mengembalikan ciphertext menjadi pesan asli.

03 — KOMPONEN

Pasangan Kunci RSA

🔓

Public Key

Kunci yang dapat dibagikan dan digunakan untuk mengenkripsi pesan.

🔒

Private Key

Kunci rahasia yang digunakan untuk mendekripsi pesan.

📋

OAEP

Mekanisme padding yang digunakan bersama RSA untuk proses enkripsi.

04 — SIMULASI

Coba RSA-OAEP

Generate key terlebih dahulu, kemudian masukkan pesan untuk mencoba proses enkripsi dan dekripsi.

Hasil proses akan muncul di sini...

RSA-OAEP cocok untuk mengenkripsi data berukuran relatif kecil. Dalam sistem nyata, RSA biasanya digunakan untuk melindungi kunci simetris, bukan mengenkripsi file besar secara langsung.
