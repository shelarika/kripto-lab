Feistel Network

Model struktur Block Cipher yang digunakan untuk memahami bagaimana proses enkripsi dan dekripsi dilakukan melalui beberapa ronde.

01 · OVERVIEW

Mengenal Feistel Network

Feistel Network merupakan sebuah struktur yang membagi blok data menjadi dua bagian, yaitu bagian kiri (L) dan bagian kanan (R).

Pada setiap ronde, salah satu bagian diproses menggunakan fungsi tertentu bersama kunci ronde, kemudian hasilnya digunakan untuk memengaruhi bagian lainnya.

Struktur ini membantu memahami bagaimana sebuah sistem Block Cipher dapat melakukan proses enkripsi dan dekripsi.

02 · HOW IT WORKS

Alur Proses

INPUT Plaintext Data asli
→
ROUND L & R Pembagian blok
→
PROCESS F(L/R, K) Fungsi + kunci
→
OUTPUT Ciphertext Data terenkripsi
BASIC FORMULA

Proses setiap ronde

R Lbaru = Rlama
L Rbaru = Llama ⊕ F(Rlama, K)
