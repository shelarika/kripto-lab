# Kripto Lab – Proyek UTS
Aplikasi web (HTML, CSS, JavaScript murni) untuk 4 topik: Block Cipher, Stream Cipher, berdasarkan fungsi utama, dan berdasarkan dasar matematika algoritma.

## Menjalankan
1. Buka folder di VS Code.
2. Pasang ekstensi Live Server, klik kanan `index.html`, pilih Open with Live Server.
   (Atau klik dua kali `index.html` untuk membuka di browser.)

## Struktur
- `index.html`: kerangka halaman
- `style.css`: tampilan
- `js/util.js`: fungsi bersama (muat paling awal)
- `js/block.js`, `js/stream.js`, `js/fungsi.js`, `js/matematika.js`: satu file per judul
- `js/ui.js`: tab dan tombol bantu (muat paling akhir)
- `JOBDESK.md`: pembagian tugas dan jadwal

Catatan: Feistel, RC4, LFSR, dan RSA di sini untuk pembelajaran, bukan untuk mengamankan data sungguhan.
