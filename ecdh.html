KEY AGREEMENT

ECDH

Elliptic Curve Diffie-Hellman untuk membentuk shared secret antara dua pihak menggunakan kriptografi kurva eliptik.

01 — PENGENALAN

Apa itu ECDH?

「 」

ECDH atau Elliptic Curve Diffie-Hellman merupakan algoritma pertukaran kunci yang memungkinkan dua pihak menghasilkan shared secret tanpa mengirimkan secret tersebut secara langsung.

Masing-masing pihak memiliki private key dan public key. Public key dapat dibagikan, sedangkan private key harus tetap dirahasiakan.

Setelah proses pertukaran public key, kedua pihak dapat menghitung shared secret yang sama.

02 — PROSES

Cara Kerja ECDH

01

Key A

Pihak A membuat pasangan private key dan public key.

02

Key B

Pihak B juga membuat pasangan private key dan public key.

03

Tukar Public Key

Kedua pihak saling bertukar public key.

04

Shared Secret

Masing-masing pihak menghitung shared secret menggunakan private key sendiri dan public key pihak lainnya.

03 — KONSEP

Komponen ECDH

🔒

Private Key

Kunci rahasia yang digunakan untuk menghitung shared secret.

🔓

Public Key

Kunci yang dapat dibagikan kepada pihak lain.

🤝

Shared Secret

Nilai rahasia yang dihasilkan oleh kedua pihak dan seharusnya sama.

04 — SIMULASI

Coba ECDH

Simulasikan proses pertukaran kunci antara dua pihak dan lihat apakah shared secret yang dihasilkan sama.

Hasil proses akan muncul di sini...

Shared secret tidak perlu dikirimkan melalui jaringan. Kedua pihak dapat menghasilkan nilai yang sama berdasarkan private key masing-masing dan public key pihak lainnya.
