PUBLIC KEY CRYPTOGRAPHY

RSA

Algoritma kriptografi asimetris yang menggunakan pasangan kunci publik dan kunci privat.

01 — PENGENALAN

Apa itu RSA?

✎ᝰ.

RSA merupakan algoritma kriptografi asimetris yang menggunakan dua buah kunci, yaitu public key dan private key.

Public key dapat digunakan untuk melakukan enkripsi, sedangkan private key digunakan untuk melakukan dekripsi.

Keamanan RSA berkaitan dengan sulitnya memfaktorkan bilangan besar hasil perkalian dua bilangan prima.

02 — PROSES

Cara Kerja RSA

01

Pilih Bilangan Prima

RSA menggunakan dua bilangan prima, yaitu p dan q.

02

Buat Modulus

Hitung n dengan perkalian p × q.

03

Buat Kunci

Nilai e digunakan sebagai public exponent dan d sebagai private exponent.

04

Enkripsi & Dekripsi

Pesan dienkripsi menggunakan public key dan didekripsi menggunakan private key.

03 — RUMUS

Rumus Dasar RSA

Modulus: n = p × q

Totient: φ(n) = (p − 1)(q − 1)

Enkripsi: C = Me mod n

Dekripsi: M = Cd mod n

Public Key = (e, n)

Private Key = (d, n)
