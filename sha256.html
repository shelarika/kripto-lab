HASH FUNCTION

SHA-256

Algoritma hash dari keluarga SHA-2 yang menghasilkan nilai hash sepanjang 256-bit.

01 — PENGENALAN

Apa itu SHA-256?

SHA-256 atau Secure Hash Algorithm 256-bit merupakan fungsi hash yang menghasilkan nilai hash dengan panjang 256-bit.

Hasil SHA-256 biasanya ditampilkan dalam bentuk hexadecimal sepanjang 64 karakter. Perubahan kecil pada input akan menghasilkan nilai hash yang berbeda.

Pada Kripto Lab, kamu dapat memasukkan teks untuk melihat hasil hash SHA-256 secara langsung.

02 — PROSES

Cara Kerja SHA-256

01

Input Data

Data dengan panjang bebas dimasukkan ke dalam algoritma SHA-256.

02

Padding

Pesan diberi padding agar panjangnya dapat diproses dalam blok 512-bit.

03

Compression

Setiap blok diproses melalui fungsi kompresi SHA-256 sebanyak 64 ronde.

04

Hash 256-bit

Proses menghasilkan nilai hash akhir sepanjang 256-bit atau 64 karakter hexadecimal.

03 — KARAKTERISTIK

SHA-256

Ukuran blok: 512-bit

Ukuran output: 256-bit

Output hexadecimal: 64 karakter

Jumlah ronde: 64 ronde
