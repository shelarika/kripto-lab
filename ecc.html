ELLIPTIC CURVE CRYPTOGRAPHY

ECC

Kriptografi berbasis kurva eliptik yang memanfaatkan operasi matematika pada titik-titik di atas kurva.

01 — PENGENALAN

Apa itu ECC?

⌞ ⌝

Elliptic Curve Cryptography (ECC) adalah pendekatan kriptografi yang menggunakan struktur matematika kurva eliptik.

Operasi utama pada ECC dilakukan terhadap titik-titik yang berada pada kurva, termasuk penjumlahan titik dan perkalian skalar.

ECC banyak digunakan dalam sistem kriptografi modern karena dapat memberikan tingkat keamanan yang tinggi dengan ukuran kunci yang relatif kecil.

02 — PROSES

Konsep Dasar ECC

01

Tentukan Kurva

Kurva eliptik ditentukan berdasarkan parameter matematika tertentu.

02

Pilih Titik

Sebuah titik dasar G digunakan sebagai bagian dari sistem.

03

Private Key

Pengguna memilih sebuah bilangan rahasia sebagai private key.

04

Public Key

Public key diperoleh dari perkalian skalar private key dengan titik dasar.

03 — RUMUS

Persamaan Kurva

Persamaan umum: y² = x³ + ax + b

Perkalian skalar: Q = dG

G = titik dasar

d = private key

Q = public key

04 — SIMULASI

Coba ECC

Simulasi berikut menggunakan kurva eliptik sederhana di atas finite field agar operasi titik dapat diamati secara langsung.

Parameter Kurva

Titik Dasar G
