HASH FUNCTION

SHA-512

Algoritma hash dari keluarga SHA-2 yang menghasilkan nilai hash sepanjang 512-bit.

01 — PENGENALAN

Apa itu SHA-512?

SHA-512 atau Secure Hash Algorithm 512-bit merupakan fungsi hash dari keluarga SHA-2. Algoritma ini menghasilkan nilai hash sepanjang 512-bit.

Hasil SHA-512 biasanya ditampilkan dalam bentuk hexadecimal sepanjang 128 karakter. Seperti fungsi hash lainnya, perubahan kecil pada input dapat menghasilkan nilai hash yang sangat berbeda.

Pada Kripto Lab, kamu dapat memasukkan teks kemudian melihat hasil hash SHA-512 secara langsung.

02 — PROSES

Cara Kerja SHA-512

01

Input Data

Data dengan panjang bebas dimasukkan sebagai input algoritma.

02

Padding

Pesan diberi padding agar dapat diproses dalam blok berukuran 1024-bit.

03

Compression

Setiap blok diproses melalui fungsi kompresi SHA-512 dalam beberapa ronde.

04

Hash 512-bit

Hasil akhir berupa nilai hash sepanjang 512-bit atau 128 karakter hexadecimal.

03 — KARAKTERISTIK

SHA-512

Ukuran blok: 1024-bit

Ukuran output: 512-bit

Output hexadecimal: 128 karakter

Jumlah ronde: 80 ronde
