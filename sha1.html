HASH FUNCTION

SHA-1

Algoritma hash yang mengubah data dengan panjang bebas menjadi nilai hash berukuran 160-bit.

01 — PENGENALAN

Apa itu SHA-1?

SHA-1 atau Secure Hash Algorithm 1 merupakan fungsi hash yang menghasilkan nilai hash sepanjang 160-bit atau 40 karakter hexadecimal.

SHA-1 bersifat satu arah. Data yang sudah menghasilkan nilai hash tidak dapat dikembalikan secara langsung menjadi data aslinya.

Pada Kripto Lab, kamu dapat memasukkan teks dan melihat nilai hash SHA-1 yang dihasilkan.

02 — PROSES

Cara Kerja SHA-1

01

Input Data

Data yang ingin diproses dimasukkan sebagai input.

02

Padding

Data diproses dengan penambahan padding agar sesuai dengan ukuran blok algoritma.

03

Proses Hash

Data diproses melalui operasi internal SHA-1 untuk menghasilkan nilai hash.

04

Hash 160-bit

Hasil akhirnya berupa nilai hash sepanjang 160-bit dalam format hexadecimal.

03 — OUTPUT

Karakteristik SHA-1

Ukuran output: 160-bit

Format: 40 karakter hexadecimal

Input: Data dengan panjang bebas

Coba SHA-1
